title: Handling Errors
---

When interacting with our API, it's important to understand the different error codes that can occur during a request. These error codes help indicate what went wrong and can guide you in troubleshooting the issue.

Below is a list of common error codes returned by the API, along with their descriptions and possible solutions.

---

## ❌ Common Error Codes

| **Code** | **ERROR_CODE** | **Description** |
|----------|-----------------|----------------|
| **400** | BAD_REQUEST | The request is malformed or contains invalid parameters. Check that all required parameters are included and correctly formatted. |
| **401** | UNAUTHORIZED_ACCESS | The request does not include valid authorization. Check that your API key or credentials are correct and properly configured. |
| **402** | INSUFFICIENT_CREDITS | Your account has insufficient credits to process the request. Add credits or check your account balance. |
| **403** | FORBIDDEN | Your plan or account entitlements do not permit the requested operation. Check your plan and feature access. |
| **404** | RESOURCE_NOT_FOUND | The requested resource does not exist. Verify the endpoint, resource ID, and parameters. |
| **409** | CONFLICT | The request conflicts with the current state of the resource, such as attempting to create a duplicate. Review the request and resource state. |
| **422** | UNPROCESSABLE_CONTENT | The request is understood, but the content cannot be processed or fails validation. Review the provided data for errors. |
| **424** | FAILED_DEPENDENCY | A required dependency failed while processing the request. Try again later or contact support if the issue persists. |
| **429** | TOO_MANY_REQUESTS | You have exceeded the allowed request rate. Wait before retrying or reduce your request frequency. |
| **500** | INTERNAL_SERVER_ERROR | An unexpected internal server error occurred. Try again later or contact support if the problem persists. |
| **503** | SERVICE_UNAVAILABLE | The service is temporarily unavailable. Try again later. |

---

## Error Response Format

Error responses share the same JSON body. Use `error_code` to branch on the error type in your code, and `message` for details.

```json
{
  "success": false,
  "error_code": "INSUFFICIENT_CREDITS",
  "message": "Insufficient credits to process this request."
}
```

---

## Error Handling Tips

- **Check the Response Body**: The `error_code` and `message` fields tell you what went wrong and help you pinpoint the issue.
- **Rate Limits**: If you encounter a **429** error, avoid sending requests too frequently. Implement exponential backoff to retry requests after waiting for the rate limit to reset.
- **Authentication**: A **401** error means your API key is missing or invalid. A **403** error means your plan does not include the requested feature. Check your key and plan.
- **Testing**: Always test your API calls in a controlled environment to ensure that the request format and parameters are correct.

> 📌 **Tip:** Always handle errors gracefully in your application. Proper error handling ensures that users have a better experience, even when things go wrong!

## How to Handle Errors in Your Code

It's good practice to incorporate error-handling logic in your API requests. Here's an example in Python for handling different types of errors:

### Python Example:

```python
import requests

url = "https://api.wav.com/api/public/v2/MusicAI"

payload = {
    "prompt": "<string>",
    "lyrics": "<string>",
    "model": "v7",
    "webhook_url": "https://example.com/my-webhook"
}

headers = {
    "Authorization": "<api-key>",
    "Content-Type": "application/json"
}

response = requests.post(
    url,
    json=payload,
    headers=headers)

if response.status_code == 200:
    print("Request successful:", response.json())
else:
    try:
        error = response.json()
        error_code = error.get("error_code")
        message = error.get("message")
    except ValueError:
        error_code, message = None, response.text

    if error_code == "INSUFFICIENT_CREDITS":
        print("Add credits to your account:", message)
    elif error_code == "UNPROCESSABLE_CONTENT":
        print("Check your request parameters:", message)
    elif error_code == "TOO_MANY_REQUESTS":
        print("Rate limit exceeded, retry later:", message)
    else:
        print(f"{response.status_code} {error_code}:", message)
```
